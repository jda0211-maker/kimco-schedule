## 📥 Inbox
- 내용 (제목), 영역(선택, 비워도 됨), 처리여부(체크박스), 생성일(생성 시간)

## ✅ Tasks
- 이름 (제목)
- 영역: 회사 / 집 / 공통
- 상태: 할 일 / 진행 중 / 완료
- 우선순위: 높음 / 보통 / 낮음
- 마감일 (날짜)
- 프로젝트 (Projects 관계)
- 루틴 (Routines 관계, 반복에서 생성된 경우)
- 메모 (텍스트)

## 📁 Projects
- 이름 (제목), 영역, 상태(계획 / 진행 중 / 보류 / 완료), 목표(텍스트), 기한(날짜)
- Tasks와 양방향 관계

## 🗓 Events
- 이름 (제목), 영역, 일시(날짜, 시작/종료), 장소, 참석자(텍스트), 캘린더 연동(체크박스), 메모

## 🔁 Routines
- 이름 (제목), 영역, 주기(매일 / 매주 / 매월 / 격주), 요일 또는 날짜(텍스트), 다음 실행일(날짜), 활성(체크박스)

## 보기(View)
오늘 / 이번 주 / 회사 / 집 / 밀린 일(마감 지났고 완료 아님)

## 변경 규칙
- 속성을 추가하거나 바꾸면 이 파일도 같이 고친다.
- 삭제는 사용자가 "삭제 너가해줘"라고 말했을 때만 한다. 평소 안 쓰는 항목은 상태를 완료/보류로 바꾼다.
