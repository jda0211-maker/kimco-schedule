# Events와 캘린더

## 원본은 Google Calendar (2026-11-15 결정)
- 약속(시간이 정해진 일정)은 **Google Calendar가 원본**이다. 회사/집 일정이 같은 구글 계정에 있다.
- Notion 🗓 Events는 캘린더에서 읽어 온 **사본 + 메모 보관용**이다. 같은 약속을 양쪽에 따로 새로 적지 않는다.
- 사용자가 새 약속을 말하면 Google Calendar에 만들고, 필요하면 Notion Events에 `캘린더 연동`을 체크해 기록한다.
- 이미 캘린더에 있는 일정을 Notion에 넣을 때는 제목과 일시가 같은 항목이 있는지 먼저 확인하고 중복을 만들지 않는다.

## 입력 원칙
- 일정을 만들기 전에 같은 시간대에 겹치는 일정이 있는지 확인하고, 겹치면 알린다.
- 종료 시간이 없으면 1시간으로 가정하되 "1시간으로 넣었다"고 알린다.
- 일정 삭제와 취소는 하지 않는다 (훅이 차단). 취소된 일정은 메모에 "취소"라고 적고 사용자가 직접 지운다.
- 일정 수정은 바꾸기 전 내용과 바꾼 내용을 한 줄로 보고한다.
