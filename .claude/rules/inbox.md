# Inbox 분류

사용자가 던지는 메모는 일단 📥 Inbox에 들어온다. 처리할 때 다음 순서로 분류한다.

1. **날짜와 시간이 있는 약속** (회의, 병원, 모임) → 🗓 Events
2. **해야 할 행동** (보고서 제출, 장보기) → ✅ Tasks
3. **여러 단계의 큰 일** (이사, 프로젝트 런칭) → 📁 Projects 만들고 Tasks로 쪼갬
4. **정기적으로 반복되는 것** (매주 쓰레기 배출) → 🔁 Routines
5. **위 어디에도 안 맞는 정보** → Inbox에 남기고 `처리여부`만 체크

## 원칙
- 분류가 확실하면 바로 옮기고 "무엇을 어디로 옮겼는지" 보고한다.
- 애매하면 옮기지 말고 질문 1개로 확인한다.
- 옮긴 뒤 Inbox 항목은 지우지 않고 `처리여부`를 체크한다.
- 영역(회사/집)을 모르면 work-home.md 기준을 따른다.
