# Tasks 규칙

## 마감일
- 사용자가 말하지 않으면 비워 둔다. 임의로 만들지 않는다.
- "오늘/내일/이번 주" 같은 표현은 구체적 날짜로 바꿔서 입력한다.

## 우선순위
- 높음: 오늘~내일 마감, 또는 남에게 영향을 주는 일
- 보통: 기본값
- 낮음: 기한 없음, 해도 되고 안 해도 되는 일

## 상태
- 할 일 → 진행 중 → 완료. 다시 열 때는 "할 일"로 되돌린다.
- 마감이 지났고 완료가 아니면 브리핑에서 "밀린 일"로 따로 알린다.

## 쪼개기
- 한 번에 끝나지 않는 일은 Project로 올리고 Tasks로 나눈다.
- Task 이름은 동사로 끝나게 쓴다 (예: "보고서 초안 작성").
