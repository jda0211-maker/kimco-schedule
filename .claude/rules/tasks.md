# Tasks 규칙

## 마감일
- 사용자가 말하지 않으면 비워 둔다. 임의로 만들지 않는다.
- "오늘/내일/이번 주" 같은 표현은 구체적 날짜로 바꿔서 입력한다.

## 우선순위
- 높음: 오늘~내일 마감, 또는 남에게 영향을 주는 일
- 보통: 기본값
- 낮음: 기한 없음, 해도 되고 안 해도 되는 일

## 상태
- 할 일 → 진행 중 → 완료. 다시 열 때는 "할 일"로 되돌린다.
- 마감이 지났고 완료가 아니면 브리핑에서 "밀린 일"로 따로 알린다.

## 루틴에서 Tasks 만들기 (2026-11-17 결정)
- 매일 아침 브리핑 예약 실행(07:00, 실제로는 07:07쯤)의 첫 단계로 한다. 대시보드의 "오늘 루틴"은 이렇게 만든 Tasks를 보여준다.
- 대상: 🔁 Routines에서 `활성`이 켜져 있고 `다음 실행일`이 오늘 이전이거나 오늘인 것.
- 만들 Task: 이름은 루틴 이름, `마감일`은 오늘, `루틴`은 해당 루틴 연결, `영역`은 루틴의 영역, 상태는 "할 일".
- 중복 방지: 같은 루틴으로 마감일이 같은 Task가 이미 있으면 새로 만들지 않는다.
- 만든 뒤 `다음 실행일`을 `주기`(매일/매주/격주/매월)만큼 뒤로 민다. `다음 실행일`이 오늘보다 한참 과거면 오늘 기준으로 다음 날짜를 계산한다 (밀린 루틴을 여러 개 만들지 않는다).
- 만든 개수는 브리핑에서 한 줄로만 알린다.

## 쪼개기
- 한 번에 끝나지 않는 일은 Project로 올리고 Tasks로 나눈다.
- Task 이름은 동사로 끝나게 쓴다 (예: "보고서 초안 작성").
