# 세션 닫기 절차

이 저장소의 세션은 기능 하나만 다룬다. 사용자가 "닫아도 돼?"라고 하면 아래 순서로 한다. 한국어로 짧게, 결론 먼저.

## 1. 대화 훑기
이 세션 대화에서 다음을 뽑는다.
- 확정된 결정 (사용자가 고른 것, 거절한 것)
- 실제로 바뀐 것 (Notion 페이지·DB·보기, 저장소 파일, 아티팩트)
- 아직 안 끝난 것과 막힌 이유
- 사용자가 두 번 이상 바로잡은 것 (규칙 후보)

## 2. 규칙·스킬·훅 점검
`.claude/rules/*.md`, `.claude/skills/`, `.claude/settings.json`, `.claude/hooks/`를 읽고 비교한다.
- 새로 적을 것: 이번에 정해졌는데 규칙에 없는 것
- 바꿀 것: 기존 규칙과 어긋나게 된 것
- 스킬로 만들 만한 반복 절차
- 훅으로 막거나 자동화할 만한 것 (실수가 있었거나 규칙만으로는 안 지켜지는 것)
각 항목에 "근거(대화의 어느 부분)"를 한 줄로 붙인다.

## 3. 적용 범위
- 규칙 파일(.md)과 스킬: 사용자가 확인한 것만 고친다.
- **훅은 제안만 한다.** 임의로 고치지 않는다.
- 판단이 갈리는 것은 AskUserQuestion으로 묻는다.

## 4. 요약 저장
- 요약 아티팩트를 Artifact 도구로 만든다. 한 화면 분량: 한 줄 결론 / 한 것 / 결정 / 남은 일 / 규칙·스킬·훅 후보 / 다음 세션 시작 문장.
- 같은 내용을 `docs/sessions/YYYY-MM-DD-주제.md`로 저장한다.
- 커밋하고 현재 브랜치에 푸시한다. PR은 사용자가 요청할 때만 만든다.

## 5. 마무리
링크와 함께 "닫아도 됩니다"라고 한 줄로 알린다. 남은 질문이 있으면 닫기 전에 묻는다.
